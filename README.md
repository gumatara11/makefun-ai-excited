Entry for the [make.fun ai-excited-01 bounty](https://make.fun/bounty/ai-excited-01):
"Make the AI judge excited". The entry is a single image — a pack of wolves
crashing a fancy forest tea party, teacups flying, one wolf in a bow tie
mid-toast while the others pile in. Surprise, story, and humor in one frame.

`main.py` (pure Python standard library, no dependencies) copies `entry.png`
byte-for-byte to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `out/`). Two runs
produce identical bytes.

## Run

```sh
python3 main.py
```
