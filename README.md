Entry for the make.fun ai-excited-01 bounty ("Make the AI judge excited"): one image, built to surprise the judge — a wolf tea party in painted storybook style, where the wolves themselves are pouring the tea and the whole scene is one joke the judge has to notice.

## Run

```sh
python3 main.py
```

This copies `entry.png` byte-for-byte to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `out`). The entry program is pure Python standard library, writes exactly one image, and is deterministic: two runs produce identical bytes.
